# TICTACTOE
TicTacToe Java is a simple, interactive implementation of the classic Tic‑Tac‑Toe game built using core Java. The project focuses on clean logic, modular design, and a smooth user experience through the console. It’s perfect for beginners learning Java or anyone exploring basic game development concepts.  
🎮 Features
Two‑player mode (Player X vs Player O)

Valid move detection

Automatic win/draw checking

Clear board display after every turn

Lightweight, beginner‑friendly code structure

🧠 Concepts Used
Arrays / 2D arrays

Loops & conditionals

Functions for modularity

Basic game logic

Input handling
